# Getting your live link — GitHub Pages (free, ~10 minutes)

Your lecturer needs a working URL, not just these files. GitHub Pages gives you one for free, with no login required for whoever opens it.

## Steps

1. **Create a GitHub account** (if you don't have one) at github.com — free.
2. Click **"+" → New repository** (top right). Name it something like `epro506-portfolio`. Set it to **Public**. Don't add a README. Click **Create repository**.
3. On the new repo page, click **"uploading an existing file"** (or drag-and-drop).
4. Drag in **all 8 items** from this folder: `index.html`, `economic.html`, `social.html`, `cultural.html`, `health.html`, `crisis.html`, `style.css`, `script.js`, and the whole `charts` folder. Commit the upload.
5. Go to the repo's **Settings** tab → **Pages** (left sidebar).
6. Under "Build and deployment", set **Source** to "Deploy from a branch", branch **main**, folder **/ (root)**. Click **Save**.
7. Wait about a minute, then refresh — GitHub will show your live URL, something like:
   `https://yourusername.github.io/epro506-portfolio/`

That's your submission link. Test it yourself in an incognito/private window first (the same check your unit brief asks for) to confirm it opens cleanly with no login prompt.

## Before you submit

- Click through all five context pages and confirm every link works.
- Confirm the Acknowledgement popup appears on first visit and dismisses correctly.
- Check on your phone too — the site is responsive, but it's worth a look.
- Copy this exact live URL into your Canvas submission alongside the Word transcript, per your assignment's two-part submission requirement.

## If you want to update content later

Just re-upload the changed file(s) through the same GitHub web interface (Add file → Upload files) — no need to redo the whole deployment.
